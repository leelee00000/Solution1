# FlowMate 作品集截图与图文证据验证

本目录以浏览器访问 **真实线上 FlowMate** (https://leelee00000.github.io/Solution1/)。
Playwright 会按真实 UI 操作筛选、查看资格和预演面板，逐图核对文字与状态，再截取真实 PNG。

**不会**修改生产页面、不上传个人数据、不将合成图伪装为网页截图。每张图有对应的声明范围、实际 UI 状态、可见 DOM 控件、像素尺寸和 SHA256。

## 自动验证与限制

- 运行: 仓库 GitHub → Actions → Verify FlowMate portfolio screenshots。
- 产物: Actions 工件 `flowmate-evidence-<run_id>`，包含 PNG、`manifest.json`、`report.html`。
- 此工作流仅针对验证分支的脚本更改自动执行，也支持手动执行。
- GitHub 公开源站可能根据当前日期出现“待复核”标记；取证验证 UI 是否真实、文案是否对应，不背书机会实时性。
- 所谓“图文匹配验证”是**有限的程序化核对**：可见 DOM 内容 + 用户操作状态 + 浏览器截图完整性。无法完全自动判断视觉表达质量和真实性，需要人工审查。
- 验证失败时，工作流会保留已有截图和报告，并在检查中标明失败条件。
- 为避免过多自动化噪声，本验证分支独立于 `main`，不合并即可保持现网站不变。
